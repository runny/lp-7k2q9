# Login prototype

- `index.html`: the five options side by side.
- `login.html?option=A` (A to E): one option, full size. Left and right arrow keys step through them.
- `Login.vue`, `login.css`, `assets/`: the same screen as a Vue 3 component on PrimeVue 4.

Serve the folder (for example `python3 -m http.server 8000`) and open `http://localhost:8000/`.
